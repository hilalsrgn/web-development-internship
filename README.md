Web Geliştirme Stajı

Bu repo, web geliştirme stajı sürecinde günlük olarak edinilen bilgi ve becerilerin proje bazlı çıktılarını içerir. Frontend temellerinden başlayıp full-stack bir projeyle tamamlanan bir öğrenme yolculuğunu takip eder.

📚 Öğrenme Yol Haritası

Frontend: HTML → CSS → Tailwind CSS → JavaScript → React → Next.js Backend: Node.js → Express.js → REST API → Veritabanı (PostgreSQL / MongoDB) Sonuç: Full-stack proje, deployment ve portfolyo

Klasör	İçerik
gün01-html	Semantik HTML, sayfa yapısı
gün02-css	Box model, Flexbox, Grid, responsive tasarım
gün03-...	Tailwind CSS ile responsive yönetim paneli
gün04-javascript	JS temelleri, DOM, Fetch API, localStorage
gün05-yapilacaklar-projesi	Todo uygulaması (CRUD, filtreleme)
gün06-react-temelleri	React temelleri, component, state, API entegrasyonu
film-kesif-uygulamasi	Next.js ile film keşif uygulaması
mini-e-ticaret	Next.js + MongoDB + JWT ile full-stack e-ticaret projesi

🛠️ Kullanılan Teknolojiler

HTML, CSS, Tailwind CSS, JavaScript, React, Next.js, Node.js, Express.js, PostgreSQL, MongoDB, JWT, Vercel


Her proje klasörü kendi bağımsız uygulamasıdır. İlgili klasöre girip bağımlılıkları kurup çalıştırabilirsiniz:

cd <proje-klasörü>
npm install
npm run dev
